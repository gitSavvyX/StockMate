# StockMate

A small business inventory application built for the Stack & Scale Week 1 Internship Project.

## About the Project
StockMate is designed to help small shopkeepers easily track product names, prices, quantities, and low-stock items directly on their phones.

## Current Progress
### Day 1: Project Setup & UI
- Set up the React Native project using Expo.
- Built the initial Inventory List screen.
- Implemented visual stock status badges (In Stock, Low Stock, Out of Stock).
- Created UI sketches for the main screens.

### Day 2: Add Product Form & Validation
- Added an "Add Product" form with inputs for Name, Price, and Quantity.
- Implemented form validation to prevent empty fields or invalid numbers.
- Used React `useState` to dynamically update the `FlatList` and display new products instantly.

## Tech Stack
- React Native
- Expo
- TypeScript / JavaScript

## How to Run
1. Install dependencies: `npm install`
2. Start the app: `npx expo start`
3. Scan the QR code with the Expo Go app.
